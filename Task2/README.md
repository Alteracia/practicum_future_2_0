# Разделение системы на домены и моделирование потоков данных для поддержки ключевых бизнес-сценариев

| Домен  | Бизнес-сценарий |
|-|-|
| Клиника | Медецинские персонализированные данные остаются в клинике |
| Управление клиниками | Решения принимаются имя всю картину в головном офисе |
| Финтех | Более жесткие требования к безопастности |
| ИИ обучение и анализ | Работает со всеми доступными собранными данными |
| Бизнес-аналитика | Работает с золотым источником |
| Финансы | Ведение отчетности |
