Брокер событий для обмена между доменами и для near-real-time загрузок в lakehouse.

**Поддерживаемые бизнес-сценарии**

- Интеграция нового финтех-сервиса без доработки общей шины
- События клиники для ИИ-ассистента
- Снятие нагрузки и зависимости с ESB

**Почему кольцо «Trial»:** Вводим в двух доменах, расширяем по мере вывода шины из эксплуатации.
