Данные проходят путь «сырые → очищенные → витрины». Отчёты строятся по золотому слою, а не по сырым таблицам с трансформациями на лету.

**Поддерживаемые бизнес-сценарии**

- Быстрая подготовка отчётности — главная боль текущего ландшафта
- Воспроизводимость чисел: один показатель считается один раз
- Аудит происхождения показателя для регулятора

**Почему кольцо «Trial»:** Внедряется вместе с инструментом трансформаций. Без явных слоёв множество сценариев использования снова породит неуправляемое количество трансформаций.
