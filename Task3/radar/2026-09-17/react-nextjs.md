Стек интерфейса портала самообслуживания: каталог витрин, конструктор отчётов, экспорт, работа с правами.

**Поддерживаемые бизнес-сценарии**

- Сотрудник собирает отчёт сам, в пределах своего уровня доступа
- Единая точка входа в данные для всех подразделений
- Снятие части кастомных доработок с BI-системы

**Почему кольцо «Trial»:** Выбран для MVP портала. Подтверждаем на первых двух доменах, после этого фиксируем как стандарт для внутренних интерфейсов.
